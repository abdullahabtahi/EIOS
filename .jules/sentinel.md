## 2025-05-20 - Arbitrary Code Execution in Budget Threshold Parsing
**Vulnerability:** Found arbitrary code execution vulnerability in `tools/infra_checks/budget.py` where `eval()` was being used to parse Terraform/HCL configuration values (specifically `thresholds_percent`). If an attacker or malicious insider modifies an infra module to include arbitrary Python code in the list string representation (e.g. `"[__import__('os').system('malicious_command')]"`), `eval()` will execute it.
**Learning:** Tools that parse text-based configuration formats, such as HCL/Terraform files or YAMLs, are often subject to arbitrary code execution if dynamic evaluation is used blindly. Parsing string representations of lists or dicts must avoid dangerous built-ins.
**Prevention:** Always use `ast.literal_eval()` instead of `eval()` when parsing strings that represent Python literal structures (like lists, dictionaries, tuples, integers, and strings) from untrusted sources or static configuration files.
